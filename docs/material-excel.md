# 자재단가 Excel 일괄관리

좌측 `자재·경비` 메뉴 상단의 자재단가 관리에서 자재 추가/수정, 표준 양식 다운로드, 회사 전체 목록 다운로드, XLSX 업로드와 단가이력 조회를 제공합니다. 기존 구매·경비 및 사용자재 기능은 유지합니다.

양식은 자재코드, 자재명, 규격, 단위, 공종, 제조사, 공급업체, 최근매입가, 기준원가, 기준판매단가, 부가세 포함여부, 적용일, 비고 순서입니다. 예시 5행은 실제 데이터에 맞게 수정/삭제하세요. 가격은 0 이상의 원 단위 정수, 적용일은 YYYY-MM-DD 또는 Excel 날짜 셀, 부가세는 포함/미포함으로 입력합니다. XLSX 첫 시트의 헤더 순서를 유지하세요. 수식 셀은 값으로 붙여넣어야 합니다. 빈 가격은 0, 빈 적용일은 미지정으로 처리합니다. 최대 파일 10MB / 데이터 2,000행을 지원합니다.

미리보기는 아직 DB에 반영하지 않습니다. 코드가 있으면 현재 회사 코드로 매칭하고, 코드가 없으면 품명+규격+단위로 매칭합니다. 신규 무코드 품목은 UUID 코드를 생성합니다. 기존품목의 고객금액분류(재료비/노무비/경비)는 보존합니다. 전체 목록은 노무 및 경비 단가도 포함하며, 신규 품목은 재료비로 등록합니다. 필요한 분류는 자재 수정에서 변경할 수 있습니다.

행별 신규/수정/변경없음/오류와 전체 요약을 표시합니다. 동일 파일의 중복 코드/동일 품목은 관련 모든 행을 오류로 표시합니다. 오류가 있어도 정상행만 반영할 수 있습니다. 오류행은 Excel에서 수정하고 `수정한 파일 다시 업로드`를 통해 새 미리보기를 받은 후 전체 반영할 수 있습니다. 잘못된 값·수식·날짜·누락을 검증합니다. 미리보기 이후 변경된 대상은 409 충돌로 전체 반영을 중단합니다. 반영 재요청은 같은 작업을 반복 적용하지 않습니다.

매입가/기준원가/판매단가 변경 및 신규 등록은 회사·자재 ID·전후 가격·적용일·변경일·수동/Excel 업로드·사용자 ID 이력을 남깁니다. 설명 등 정보만 바뀌면 가격이력을 추가하지 않습니다. 신규의 변경 전 금액은 null로 저장합니다. 기존 표준작업 단가 수정 API도 동일 이력 경로를 사용합니다.

새 견적에서 DB/즐겨찾기를 클릭하면 현재 회사의 최신 단가를 다시 조회합니다. 자동단가 OFF에서는 0원으로 추가하며 수동 수정할 수 있습니다. 합산 시 기존 행의 모든 단가를 보존합니다. 기존 견적/표준작업 버전 스냅샷은 변경하지 않습니다. 명시적 최신단가 재적용 기능을 위한 공통 `reapplyLatestQuotePrices` 함수를 준비했으며, 자동으로 호출하지 않습니다. 향후 버튼 연결 시 사용자가 명시적으로 요청한 경우에만 호출해야 합니다.

API: GET `/material-prices/template`, GET `/material-prices/export`, POST `/material-prices/imports/preview` (multipart file), GET `/material-prices/imports/:id`, POST `/material-prices/imports/:id/apply` ({mode: 정상행만|전체}), GET `/material-prices/:id/history`. 모두 현재 회사의 관리자 권한이 필요합니다. 업로드 및 조회 작업 ID와 가격이력도 회사별 메모리 저장소로 분리합니다.

PostgreSQL 이전 시 `materials`는 company_id+자재코드 복합 유일키, `material_price_history`는 회사/자재 FK와 변경 전후 가격, `material_import_jobs`는 회사/작성자/상태/파일명/반영일, `material_import_rows`는 회사/작업 FK/원본행번호/값/오류/대상스냅샷을 사용합니다. 반영은 트랜잭션에서 대상 행 잠금 또는 revision 비교와 상태 전환을 함께 수행해야 합니다. 현재 메모리 어댑터는 동기 일괄 반영하며 서버 재시작 시 초기화됩니다. 기존 일일작업 사용자재 엔터티와 단가 카탈로그의 관계는 향후 동일 회사 재료 FK로 이전할 때 통합하되, 현재 사용 기록을 수정하지 않습니다.
