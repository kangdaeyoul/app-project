# 모바일 견적 작성 간편화

## 구성

- 새 견적에 빈 품목행을 만들지 않는다. 공종 선택 후 한 건을 입력하고 추가한다. 추가 후 입력칸은 초기화되고 품명에 다시 포커스된다.
- 기본 입력: 품명, 규격, 수량, 단위, 판매단가. 내부 재료/노무/경비 단가는 상세입력에 접어둔다.
- PC는 좌측 입력/우측 견적표, 모바일은 입력 아래 견적표. 표 목록만 내부 스크롤하므로 품목 수가 늘어도 입력폼 위치가 아래로 밀리지 않는다.
- 행에서 수량·단가 수정과 확인 후 삭제가 가능하다. 상세에서 공종·품명·규격·단위·비고·내부 원가·금액 분류·계산근거를 확인/수정한다.
- 수량과 단가는 편집 문자열을 숫자 모델과 분리한다. 빈칸과 명시적으로 입력한 0을 구분해 편집하며, 계산/저장 모델에는 숫자를 전달한다. 수량을 비운 상태로 저장하면 API 양수 검증이 적용된다.
- 일반관리비/착준공지원비 및 내부 비용, 기존 빠른입력과 표준작업 숫자 입력에도 같은 편집 처리를 적용한다.
- 품목 검색·DB·즐겨찾기·표준작업은 기존 품목 추가 대화상자를 재사용한다. DB/즐겨찾기 추가 후 닫혀 현재 표에 바로 반영된다. 표준작업은 예상 구성품 수/금액을 먼저 표시하고 상세는 구성품 보기를 눌러 연다.
- 저장 액션바는 PC 우측 하단, 모바일 하단 메뉴 위에 고정된다. 품목 수/공급가액/VAT/총액을 표시한다. 비용 상세는 갑지 총괄에서 펼친다.
- 이름 없는 행은 화면에 표시하지 않고 저장 시 제외한다. API는 이름 없는 신규 입력을 거부하고 고객 출력에서도 이름 없는 행을 제외한다. 이름이 있는 미등록 단가 품목과 실제 0원 품목은 임의 삭제하지 않는다. 기존 Excel 양식의 빈 셀/서식은 유지한다.
- 검증 중 발견한 웹 프록시의 일시적인 연결 끊김(ECONNRESET/비JSON 500) 때문에 조회 실패 후 새 견적 버튼이 비활성화되던 문제를 보완했다. 견적 조회 GET만 한 번 재시도한다. 저장 POST/PUT는 중복 등록을 막기 위해 자동 재시도하지 않는다.
- 기존 견적 계산, 원가/고객 가격 분리, 단가 자동입력, 중복 합산, 공종/조건별 산출, PDF/종로소방 Excel 양식을 유지한다. DB 마이그레이션은 필요 없다.

## 검증

- 빌드와 TypeScript 검사 통과.
- API 테스트 80개 통과. 기존 견적 입력 검증에 빈 품명/공백 품명 저장 차단 검증 추가.
- Chromium PC 1440×1000, iPhone 크기 390×844, Android 크기 412×915로 브라우저 검증.
- 화재감지기 5개, 유도등 3개, 발신기세트 1개, HFIX 1.5SQ 30m, 스프링클러헤드 4개를 입력하고 추가 5건까지 총 10건 등록.
- 입력 즉시 표 반영, 입력 초기화, 모바일 입력 위치 유지, 숫자 0 삭제 후 빈칸 유지, 상단/하단 스크롤 시 저장 버튼 노출, 수량/판매단가 즉시 수정 및 저장 후 값 보존 확인.
- 공종별 표준작업 선택, 구성품 접힘, 견적 반영, 즐겨찾기 반복 선택 합산, 규격 차이가 있는 행 분리, 수정단가 보존을 PC/모바일 크기에서 확인.
- 실제 PDF/Excel API 응답 생성 확인. Excel에서 다섯 품목 확인. PDF 텍스트 추출로 한글 품목/규격 확인 및 내부원가/마진 문구 미노출 확인. 이름 없는 자동 품목행이 생성되지 않는지 확인.
- 현장 조회에 비JSON 500 응답을 한 번 주입한 PC/모바일 검증에서 재조회 후 새 견적 작성이 정상 동작하는지 확인. 변경/저장 요청은 재시도 대상으로 지정하지 않음.
- 실제 휴대폰/Safari 엔진 검증은 아니며 화면 크기 에뮬레이션 결과이다.

## 변경 파일

- `apps/admin-web/app/quote-line-editor.tsx`: 한 건 입력/즉시 견적표/빠른 수정.
- `apps/admin-web/app/quote-number-input.tsx`: 빈 숫자 입력 상태 보존.
- `apps/admin-web/app/quotes-panel.tsx`: 기존 편집 연결, 빈 행 제외, 고정 저장/총괄 접기.
- `apps/admin-web/app/quote-quick-input.tsx`: 공종 연결, 숫자 입력/추가 후 초기화 및 대화상자 닫기.
- `apps/admin-web/app/standard-work-quick.tsx`: 구성품 요약/접기 및 숫자 편집.
- `apps/admin-web/app/globals.css`: PC 분할/모바일 배치/스크롤 표/고정 액션바.
- `apps/api/src/quotes.service.ts`: 고객 출력에서 이름 없는 행 제외.
- `apps/api/test/quotes.test.ts`: 빈 품명 저장 차단 회귀 검증.
