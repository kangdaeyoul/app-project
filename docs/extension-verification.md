# 사용자·정산·실적·범용 Excel 및 캐릭터 검증

2026-10-11, 메모리 저장소 및 로컬 `npm run start:preview`에서 검증했습니다.

- 프로젝트 빌드와 TypeScript 타입 검사가 통과했습니다.
- API 테스트 75개가 통과했습니다. 기존 현장/견적/표준작업/자재단가/사진/수금/일부지급/A/S/보고서 PDF/템플릿 Excel/감사로그/회사 격리 테스트를 포함합니다.
- 추가 API 테스트(`apps/api/test/business-extension.test.ts`): 가입 신청 → 승인 전 차단 → 승인 → 내정보/비밀번호 변경 → 기존 세션 폐기 → 잠금 차단, 다른 회사의 가입/조회 격리, 마지막 관리자 보호를 확인했습니다. 수금 상태/초과입금/월 집계/실적 검토·미입력 검증/Excel·CSV와 범용 XLS/XLSX 매핑/단가 변경이력/중복 유지/다른 회사 업로드 ID 차단도 확인했습니다.
- 실제 브라우저에서 관리자·직원·작업진행자 1/2의 직접 이메일 로그인과 데모 버튼 8가지 경로 모두 역할별 첫 화면과 세션 응답까지 확인했습니다. 비활성 계정은 실패하고 세션이 생기지 않습니다.
- `DEMO_LOGIN_ENABLED=false`에서 관리자 직접 로그인 실패를 재현했습니다. API 진단 로그는 `account missing (demo seed disabled or unknown login)`으로 원인을 구분했습니다. 기본 로컬 미리보기 실행에서 다시 성공하는 것을 확인했습니다. [실패 재현 화면](screenshots/login-failure-reproduced.png)
- 모바일 가입 신청/승인 대기 차단 → PC 관리자 승인 → 모바일 로그인 → 내정보 수정까지 실제 브라우저로 확인했습니다.
- PC 수금 등록, 월간 카드, 실적 대상 지정, 실제 Excel/CSV 다운로드, 다른 헤더의 XLS 파일 매핑/미리보기/반영/같은 형식 매핑 재사용을 확인했습니다.
- Android 412×915, iPhone 390×844: 관리자 정산/실적/자재/사용자관리와 작업진행자 홈/달력/휴무·오전불가/기존 배정 충돌 확인/주간 계획/알림/내정보를 확인했습니다. 작업진행자 금액 API는 403이며 회사/타인 범위 차단도 API 테스트에서 확인합니다.
- 견적 브라우저 회귀: 전기/기계 필터, 전체 검색, 즐겨찾기 누적, 수동단가 12,345원 보존, 자동단가 OFF, 자동합산 OFF, 수동 품목 입력 및 저장, 기존 Excel 갑지·을지 3개 시트와 인쇄영역이 정상입니다.
- 캐릭터는 PC/Android/iPhone 업무화면에서 같은 자산을 사용합니다. PWA 오프라인 안내를 확인했고 캐릭터 공개 자산만 캐시하며 API/업무 데이터는 캐시하지 않습니다.

현재 회사·사용자·실적·매핑·업무 저장소는 메모리이며 API 재시작 시 초기화됩니다. 협회 공식 신고/은행/홈택스/Supabase Auth는 연결하지 않았습니다. 원본 브로셔 캐릭터 파일은 대화에 제공되지 않아 설명을 기준으로 제작했습니다.
