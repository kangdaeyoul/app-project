# 모바일 홈과 첫 사용 가이드

## 홈과 이동

- 홈은 오늘 요약 → 컴팩트 월간 달력 → 오늘 현장/A/S → 미처리 알림 → 빠른 실행 순서입니다. 오늘 목록은 각각 2건을 먼저 보여주고 전체보기로 연결합니다.
- 달력은 기존 `/worker-schedule`을 조회합니다. 회사/배정 권한은 서버에서 검증하며 별도 일정 데이터를 생성하지 않습니다. 현장·A/S·완료·긴급·미배정을 기호/건수와 접근성 문구로 표시하고 배정에는 人을 표시합니다. 날짜 선택 시 담당 작업진행자와 상태를 확인할 수 있습니다.
- 모바일 상세/등록/수정 화면에는 44px 이상의 `← 이전` 버튼이 나타납니다. 기존 화면의 목록/취소 동작을 재사용합니다.
- 왼쪽 20px 이내에서 시작해 수평 80px 이상 움직이는 제스처만 사용합니다. 표·가로스크롤·사진/PDF·달력·입력 요소는 제외합니다. iPhone Safari 일반 탭에서는 브라우저 기본 제스처를 유지하고 설치형 PWA에서는 보완 제스처를 사용합니다. 같은 히스토리 처리로 중복 이동을 방지합니다.
- 편집 중 이탈은 `나가기 / 계속 작성`으로 확인합니다. 새로고침/탭 닫기는 브라우저 기본 경고를 사용합니다. 파일 선택만으로 저장된 것으로 처리하지 않습니다.

## 체험 로그인

체험 버튼을 눌러도 안내창에서 시작하기 전에는 인증 요청을 보내지 않습니다. 관리자·사내직원·작업진행자의 권한에 맞춰 안내합니다.

- **체험 시작**: 홈으로 이동하며 자동 튜토리얼을 생략합니다.
- **튜토리얼과 함께 시작**: 역할별 가이드를 첫 단계부터 실행합니다.
- **취소**: 로그인하지 않습니다.

서버의 `isDemo` 표시를 사용하는 체험판 배지는 샘플 계정의 이메일 직접 로그인에도 적용됩니다. 사용자가 가입 요청에 해당 값을 넣어도 체험 계정으로 지정되지 않습니다.

도움말의 튜토리얼 예시는 회사/사용자별 별도 저장소에 있습니다. 삭제/재생성/선택한 예시 되돌리기는 **이 별도 예시만** 변경합니다. 기존 공용 업무 샘플과 실제로 입력한 회사정보·현장·견적은 지우지 않습니다. 공용 샘플까지 모두 삭제하는 기능은 제공하지 않습니다.

## 관리자 초기설정

`/initial-setup`은 관리자만 접근할 수 있고 회사 및 사용자 범위를 검증합니다. 회사정보·로고/직인·사용자 확인·작업진행자·거래처·자재·견적 설정·현장 등 8개 항목을 계산합니다.

등록 여부는 실제 저장소를 조회합니다. 사용자 정보와 견적 설정은 관리자가 검토 완료를 선택하며 로고/직인은 사용하지 않을 경우 명시적으로 생략할 수 있습니다. 완료 시 홈 카드가 사라지고 도움말에서 다시 열 수 있습니다. 처음 시작 안내는 건너뛰어도 업무가 차단되지 않습니다.

회사 설정은 **회사정보 수정 → 저장 또는 취소** 흐름입니다. 저장 후 새 문서부터 적용되며 기존 견적의 회사정보 스냅샷은 유지합니다. 체험 관리자는 도움말에서 별도 예시 회사정보를 수정·복원할 수 있습니다.

**저장 한계:** 현재 인증/회사/튜토리얼 저장소 정책을 유지합니다. 초기설정 검토 상태는 서버 메모리이며 첫 안내 확인은 사용자/회사별 브라우저에도 저장합니다. 서버 재시작 시 검토 확인을 다시 해야 할 수 있습니다. Supabase 전환과 영구 사용자별 진행상태 저장은 보류 중이며 이번 배포에서 활성화하지 않습니다.

## 검증

실행 결과와 제한은 작업 완료 보고를 참고하세요. 반응형 브라우저 크기는 iPhone 375×667, Android 360×740, PC 1440×1000입니다. 설치형 상태는 `navigator.standalone`을 모사하고 실제 Service Worker 등록을 확인합니다. 물리 iPhone Safari/Android 기기에서의 OS 제스처·홈 화면 실제 설치는 별도 실기기 확인이 필요합니다.

스크린샷: [검증 화면](screenshots/mobile-first-use/).

이번 검증: API 88개 통과, PC/iPhone/Android 크기 × 체험 4역할의 12개 조합에서 안내 취소·체험 시작·튜토리얼 시작·예시 삭제/재생성 확인. 신규 일반 관리자 3개 화면 크기에서 이메일 로그인·첫 설정 안내·회사정보 수정/저장·로고/직인 업로드·다시 열기·기존 견적 스냅샷 보존을 확인했습니다. Chromium의 설치 상태 모사에서 가장자리/중앙 스와이프 구분·이탈 확인·히스토리 뒤로가기·설정 완료 후 카드 숨김·도움말 다시보기를 확인했습니다. 실기기 Safari/PWA의 OS 제스처는 미검증입니다.
