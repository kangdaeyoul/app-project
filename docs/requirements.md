# 요구사항과 구현 범위

서비스명: 종로소방 통합 현장관리

장기 구조: PC 관리자 웹 + iOS/Android Flutter 앱 + 공통 API + PostgreSQL. 이번 단계에서는 관리자 웹, API, 공통 계약만 구현합니다.

## 현재 구현

좌측 메뉴: 홈 / 현장 / 견적 / 작업진행자 / 일일작업 / 자재·경비 / 정산 / 실적 / 출력.

홈에는 월간 달력, 오늘 현장 목록, 진행중·완료·미배정 건수, 월 계약매출, 수금액, 미수금, 작업진행자 미지급액과 월별 현장 목록을 표시합니다. 달력에서 이전/다음 달을 조회할 수 있습니다. 현장 메뉴는 전체 목록·검색·상태 필터·등록·수정·상세를 제공하고 다른 주 메뉴는 준비 안내를 표시합니다.

API가 샘플 현장 데이터를 제공하고 프론트엔드는 동일 출처 프록시로 조회합니다. 날짜 기준은 Asia/Seoul, 금액 단위는 원입니다. 집계는 조회 월의 샘플 현장 기준이며 미수금은 계약금액 합계에서 수금액 합계를 뺀 값입니다. 샘플의 오늘 현장은 실제 작업 데이터가 아닙니다.

## 이후 단계

1. PostgreSQL 저장소 어댑터, 마이그레이션 및 현장/작업진행자 CRUD.
2. 로그인, 역할별 권한 및 변경 이력.
3. 견적, 일일작업, 자재·경비, 수금/지급 원장과 실적/출력.
4. 파일 저장 인터페이스와 NAS 어댑터, 업로드 검증.
5. Flutter 앱, 동일 API 계약, 현장 작업 입력 및 사진 첨부.

현장 기본정보는 API 메모리에 저장됩니다. 서버 재시작 시 샘플로 초기화되며 영구 저장·인증·파일 업로드는 제공하지 않습니다. 실제 운영의 집계는 계약/수금/지급 원장과 업무 규칙을 합의한 뒤 구현해야 합니다.

## 현장 기본 관리

목록: 현장명, 거래처, 주소, 공사내용, 공사일정, 대표 작업진행자, VAT 포함 공사금액, 입금액, 미수금, 진행상태.

등록/수정: 현장명(필수), 거래처, 주소, 현장 담당자, 연락처, 공사내용, 시작일(필수), 종료예정일, VAT 포함 공사금액(기본 0), 대표 작업진행자, 진행상태(기본 미배정). 종료예정일은 시작일보다 빠를 수 없으며 금액은 0 이상의 안전한 정수입니다.

상세: 상단 기본정보, 개요/일정/일일작업/사진/자재·경비/수금/작업진행자 정산/파일 탭. 현재 기본정보·일일작업 등록/수정과 샘플 누계 조회가 가능하며 사용자재 등록 및 현장 합계 조회를 제공하며 첨부는 다음 단계입니다.

일정: 시작일부터 종료일까지 달력에 표시합니다. 종료예정일이 없으면 시작일에만 표시합니다. 월간 집계는 해당 월과 기간이 겹치는 공사의 전체 누계이며 매출의 월별 배분은 후속 단계입니다. 날짜 이동으로 샘플을 재생성하지 않습니다.

## 작업진행자 관리

이름/표시명 분리 등록·수정, 연락처/업무 역할/메모/기본 근무 상태, 전체 목록 검색·월 조회, 상세 6개 탭과 날짜별 근무 상태 등록을 제공합니다. 삭제된 진행자 포함 조회가 가능하며 기존 현장 기록을 보존합니다. 실제 로그인 권한, 지급 처리, 자동 배정 제한은 후속 단계입니다. 일일작업 입력은 별도 메뉴와 상세 탭에서 제공합니다. 집계 정의와 API는 README를 참조합니다.

## 일일작업 관리

현장과 대표 작업진행자 ID는 필수이며 참여 작업자는 체크박스로 여러 명 선택합니다. 작업일자, 시작/종료시간, 내용, 특이사항, 4가지 상태(작업예정/작업중/작업완료/관리자확인완료)를 저장합니다. 오늘 시작/종료는 서버 서울 시각으로 기록하고 수동 수정도 가능합니다. 현장/작업진행자 상세에서 같은 기록을 필터 조회합니다. 기간 내 여러 기록을 허용하며 공사일정 밖 작업도 등록 가능합니다.

사진은 숫자 필드만 준비하며 업로드는 후속 단계입니다. 사용자재는 여러 줄 등록·수정·삭제를 제공합니다. 현장 선택은 활성/저장된 현장, 작업진행자 신규 선택은 삭제되지 않은 사람만 가능합니다. 완료 작업의 고유 참여 날짜를 작업일수로 집계하며 지급액 계산은 별도의 후속 규칙이 필요합니다.

## 실제 사용자재 등록

일일작업의 사용자재 여러 줄을 추가/수정/삭제하며 자재명, 규격, 수량, 단위, 비고만 입력합니다. 목록 건수는 연결 행 수로 계산합니다. 현장 자재·경비 탭에서는 작업일자, 자재명, 규격, 수량, 단위, 일일작업 내용/ID, 대표 작업진행자를 표시하고 자재명/규격/단위별 총사용량을 제공합니다. 실제 경비·원가·구매·영수증·사진 업로드는 이번 범위에 포함되지 않습니다.
