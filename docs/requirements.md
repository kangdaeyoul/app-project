# 요구사항과 구현 범위

서비스명: 종로소방 통합 현장관리

장기 구조: PC 관리자 웹 + iOS/Android Flutter 앱 + 공통 API + PostgreSQL. 이번 단계에서는 관리자 웹, API, 공통 계약만 구현합니다.

## 현재 구현

좌측 메뉴: 홈 / 현장 / 견적 / 작업진행자 / 일일작업 / 자재·경비 / 정산 / 실적 / 출력.

홈에는 월간 달력, 오늘 현장 목록, 진행중·완료·미배정 건수, 월 계약매출, 수금액, 미수금, 작업진행자 미지급액과 월별 현장 목록을 표시합니다. 달력에서 이전/다음 달을 조회할 수 있습니다. 현장 메뉴는 전체 목록·검색·상태 필터·등록·수정·상세를 제공하고 작업진행자·일일작업·자재경비·정산 메뉴도 등록 및 조회 기능을 제공합니다. 견적·실적·출력은 준비 안내를 표시합니다.

API가 샘플 현장 데이터를 제공하고 프론트엔드는 동일 출처 프록시로 조회합니다. 날짜 기준은 Asia/Seoul, 금액 단위는 원입니다. 집계는 조회 월과 기간이 겹치는 현장의 원장 기준이며 미수금은 계약금액 합계에서 수금액 합계를 뺀 값입니다. 샘플의 오늘 현장은 실제 작업 데이터가 아닙니다.

## 이후 단계

1. PostgreSQL 저장소 어댑터, 마이그레이션 및 현장/작업진행자 CRUD.
2. 로그인, 역할별 권한 및 변경 이력.
3. 견적, 실적/출력과 사진대지 PDF.
4. 파일 저장 인터페이스와 NAS 어댑터, 업로드 검증.
5. Flutter 앱, 동일 API 계약, 현장 작업 입력 및 사진 첨부.

현장 기본정보는 API 메모리에 저장됩니다. 서버 재시작 시 샘플로 초기화되며 영구 저장·인증·외부 파일 저장소는 제공하지 않습니다. 수금/지출/지급은 메모리 원장으로 집계하며 사진 업로드도 임시 메모리입니다.

## 현장 기본 관리

목록: 현장명, 거래처, 주소, 공사내용, 공사일정, 대표 작업진행자, VAT 포함 공사금액, 입금액, 미수금, 진행상태.

등록/수정: 현장명(필수), 거래처, 주소, 현장 담당자, 연락처, 공사내용, 시작일(필수), 종료예정일, VAT 포함 공사금액(기본 0), 대표 작업진행자, 진행상태(기본 미배정). 종료예정일은 시작일보다 빠를 수 없으며 금액은 0 이상의 안전한 정수입니다.

상세: 상단 기본정보, 개요/일정/일일작업/사진/자재·경비/수금/작업진행자 정산/파일 탭. 현재 기본정보·일일작업 등록/수정과 샘플 누계 조회가 가능하며 사용자재 등록 및 현장 합계 조회를 제공하며 작업 전·후 사진 등록/조회도 제공합니다. 일반 파일 첨부는 다음 단계입니다.

일정: 시작일부터 종료일까지 달력에 표시합니다. 종료예정일이 없으면 시작일에만 표시합니다. 월간 집계는 해당 월과 기간이 겹치는 공사의 전체 누계이며 매출의 월별 배분은 후속 단계입니다. 날짜 이동으로 샘플을 재생성하지 않습니다.

## 작업진행자 관리

이름/표시명 분리 등록·수정, 연락처/업무 역할/메모/기본 근무 상태, 전체 목록 검색·월 조회, 상세 6개 탭과 날짜별 근무 상태 등록을 제공합니다. 삭제된 진행자 포함 조회가 가능하며 기존 현장 기록을 보존합니다. 실제 로그인 권한, 결제 API, 자동 배정 제한은 후속 단계입니다. 지출 원장에서 정산 상태를 기록합니다. 일일작업 입력은 별도 메뉴와 상세 탭에서 제공합니다. 집계 정의와 API는 README를 참조합니다.

## 일일작업 관리

현장과 대표 작업진행자 ID는 필수이며 참여 작업자는 체크박스로 여러 명 선택합니다. 작업일자, 시작/종료시간, 내용, 특이사항, 4가지 상태(작업예정/작업중/작업완료/관리자확인완료)를 저장합니다. 오늘 시작/종료는 서버 서울 시각으로 기록하고 수동 수정도 가능합니다. 현장/작업진행자 상세에서 같은 기록을 필터 조회합니다. 기간 내 여러 기록을 허용하며 공사일정 밖 작업도 등록 가능합니다.

사진은 독립 사진 레코드와 임시 파일 저장소로 관리하고 목록 건수는 실제 연결 행 수로 집계합니다. 사용자재는 여러 줄 등록·수정·삭제를 제공합니다. 현장 선택은 활성/저장된 현장, 작업진행자 신규 선택은 삭제되지 않은 사람만 가능합니다. 완료 작업의 고유 참여 날짜를 작업일수로 집계하며 지급액 계산은 별도의 후속 규칙이 필요합니다.

## 실제 사용자재 등록

일일작업의 사용자재 여러 줄을 추가/수정/삭제하며 자재명, 규격, 수량, 단위, 비고만 입력합니다. 목록 건수는 연결 행 수로 계산합니다. 현장 자재·경비 탭에서는 작업일자, 자재명, 규격, 수량, 단위, 일일작업 내용/ID, 대표 작업진행자를 표시하고 자재명/규격/단위별 총사용량을 제공합니다. 구매·경비는 별도 지출 원장으로 등록하며 사용자재와 자동 차감하지 않습니다. 원가배분·영수증 업로드는 후속 단계입니다.


## 작업 전·후 사진

일일작업 상세에서 여러 장 등록, 삭제, 설명/위치/촬영일시/등록자 수정 및 순서 변경을 제공합니다. 작업 전과 작업 후를 구분하며 현장 사진 탭에는 날짜별 사진과 전체/구분/작업일자 필터, 확대 미리보기를 제공합니다. 원본 파일명/저장소 키는 독립 사진 엔터티로 관리합니다. 메타데이터와 원본 모두 임시 메모리이며 재시작하면 샘플로 초기화됩니다. 샘플은 예시 그림이고 실제 사진이 아닙니다. NAS/클라우드/DB, 인증, 카메라 직접 촬영, EXIF 자동 추출, PDF, 승인 및 완료 시 필수사진 검사는 후속 단계입니다.


## 자재·경비 지출

현장 필수 및 일일작업 선택 연결로 회사 직접 자재구매/작업진행자 대납 자재구매/작업비/기타경비를 등록·수정·삭제합니다. 지출일, 품목/내용, 거래처, 수량/단위, 총 공급가액/VAT/자동 합계, 결제방법, 증빙유형, 지출자, 대납 여부, 정산완료 여부/정산일, 비고를 관리합니다. 대납 및 작업비는 작업진행자 ID를 연결하고 삭제 이후에도 스냅샷과 정산 기록을 보존합니다.

현장 탭에서 사용자재/구매자재/작업비/기타경비를 구분하고 전체 지출 및 유형별 소계를 자동 계산합니다. 기타경비 대납 소계의 중복은 총지출에 중복 반영하지 않습니다. 작업진행자 정산 탭은 새 작업비+대납 총 지급예정/완료/미지급을 표시합니다. 실제 결제 및 세금계산서 연동/영수증 업로드 없이 파일 참조만 준비합니다. 일부 지급과 지급 기록 취소도 제공합니다. 모든 신규 데이터는 기존 메모리 방식으로 저장합니다.


## 수금·지급·현장손익

다건 수금 등록·수정·삭제, 현장 계약/입금/미수 자동 계산, 현장별 정산의 작업비/자재대납/기타정산 지급예정액 및 지급완료액/잔액/상태/지급일을 제공합니다. 전액 및 일부 지급을 기록할 수 있고 지급일을 수정할 수 있습니다. 지급일 기본값은 서울 오늘입니다. 관리자 정산 메뉴에는 모든 작업진행자 요약과 현장별 정산, 수금·미수 및 현장손익 화면이 있습니다. 작업진행자 상세에서는 본인의 현장별 원장과 월 합계를 제공합니다.

현장 개요의 6개 카드(계약/입금/미수/총지출/현장차익/작업진행자 미지급) 및 대시보드는 같은 원장을 집계합니다. 현장차익은 계약−등록 지출이며 회계상 순이익이 아닙니다. 실제 지급액은 이미 기록된 지출을 다시 비용으로 더하지 않습니다. 입력 범위/월 기준/취소 정책 및 샘플 수치는 README를 참조하세요. PostgreSQL/은행/카드사/홈택스는 연결하지 않습니다.


## 세금계산서·증빙

매출은 현장·거래처·공급가액/VAT/합계·발행상태·발행일·승인번호·비고, 매입은 현장·연결 지출/구매·공급업체·공급가액/VAT/합계·수취상태·수취일·승인번호·비고를 관리합니다. 매출은 같은 현장 수금과 선택 연결하고 매입은 세금계산서 증빙유형 지출에 연결합니다. 작업진행자 계산서는 현장별 정산 그룹과 연결하며 미발행/발행완료/해당없음을 관리합니다.

정산의 증빙 화면에는 네 종류의 경고 합계와 증빙없음/계산서 미수취 필터를 제공합니다. 현장 개요·수금에 매출 상태, 자재·경비에 지출 증빙과 매입 상태, 작업진행자 정산에 계산서 상태, 대시보드에 3개 경고 카드를 표시합니다. 입력/집계 범위 및 1개 관리기록 정책은 README를 참조합니다. 사업자정보를 확장 필드로 저장하지만 외부 발행 API, 홈택스 또는 실제 발행은 연결하지 않습니다.

## 사진대지 PDF 자동생성
- 현장 상세 사진 탭에서 전체/특정 작업일자/전·후 구분/선택 사진 범위를 조합하여 출력한다. 비교형, 4장, 6장 A4 형식과 실제 PDF 미리보기를 제공한다.
- 비교형은 같은 작업일자·입력된 위치별로 순서대로 전후 사진을 매칭한다. 짝이 없거나 위치가 미입력인 사진도 모두 보존한다.
- 회사명, 현장명, 공사내용, 작업기간, 작성일 및 각 사진의 구분·위치·설명·촬영일자를 출력한다. 작업진행자(일일작업의 대표자), 번호, 촬영시간은 선택 옵션이다. 긴 위치/설명은 별첨으로 보존한다.
- 한글 폰트 삽입 및 이미지 디코딩을 완료한 실제 PDF를 다운로드한다. 원본 파일은 변경하지 않는다. 옵션 변경 시 미리보기를 무효화한다.
- 출력은 1~60장, 현재 별도 임시 PDF 저장소는 최대 20개·30분 보관이다. NAS 영구저장과 출력 이력 UI는 향후 단계다.

## 견적 관리
- 거래처 ID 및 현장 ID(선택)를 연결한다. 갑지 총괄, 기계/전기 을지와 다건 항목을 등록·수정·복사·삭제·과거 검색한다. 상태는 작성중/제출완료/수정요청/승인/계약전환/취소다. 계약전환 상태는 서버의 현장 생성으로만 설정한다.
- 내부 재료/노무/경비 단가와 고객 판매단가는 독립 필드다. 갑지 고객 재료비/노무비/경비는 각 항목의 고객금액 분류별 판매금액이다. 일반관리비·착/준공지원비도 내부 원가와 고객 청구액을 분리한다. 관리 API의 권한 정책 교체와 고객 DTO 허용 필드 분리로 향후 관리자 권한을 연결할 수 있다. 현재는 로그인 없는 샘플 관리자 환경이다.
- VAT 포함 고객 총액은 기본 천원 단위 반올림→만원 단위 표시(0.1만원까지 최종 총액 표현)다. 원 표시/반올림 없음 옵션을 제공한다. 조정액을 별도 표시해 공급가액 및 VAT와 합계를 일치시킨다. 마진은 VAT 제외 공급가액 기준이다.
- 저장된 승인 견적을 공사기간 입력 후 새 현장으로 생성한다. 고객정보/현장명/주소/공사내용/최종 총액/기계·전기 공종을 전달한다. 중복 생성 방지, 전환 후 수정·삭제 금지, 복사 가능을 보장한다. 참조로 연결한 기존 현장은 수정하지 않는다.
- 고객 견적서 PDF는 회사명/거래처/현장명/견적일/유효기간/갑지/기계·전기 을지/공급가액/VAT/총액/비고를 포함한다. 전체 상세, 단가 숨김, 금액 숨김, 공종별 묶음, 총액 위주의 5개 출력모드와 실제 PDF 미리보기를 제공한다. 내부 원가·마진은 고객 DTO와 PDF에 포함하지 않는다.
- 기계/전기/기계+전기 샘플, 한글 폰트 삽입, 메모리 저장 방식 유지. Excel 양식 복제와 실제 로그인은 다음 단계다.
