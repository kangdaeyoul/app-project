# 작업진행자 스케줄 검증 (2026-10-08)

## 자동 검증

- 루트 `npm run build`: shared/API/Next.js 프로덕션 빌드.
- 루트 `npm run typecheck`: 전체 TypeScript 검사.
- 루트 `npm test`: API 회귀 테스트 58개. 신규 스케줄 테스트는 다중 현장, 휴무/오전/오후 불가, 시간 중복, 관리자의 강제 저장, 기존 실제시간·사진·자재 및 예정시간 보존, 고유색/비활성 색상, 회사 격리, 본인 일정, 직원 현장 범위와 권한을 포함합니다.

## Chromium 실제 브라우저 검증

Playwright + 시스템 Chromium에서 관리자 웹과 API를 함께 실행하여 다음을 확인했습니다.

- PC 1440×1000: 작업진행자 6명과 겹치지 않는 초기 고유색. 대표+참여 작업진행자가 동일 일일작업에 연결됩니다.
- 완료/작업중/배정완료/긴급 상태를 색과 텍스트로 표시. 휴무·오전불가·오후불가 배경과 충돌 안내가 표시됩니다.
- 최기계 기사에게 하루 09:00–12:00 / 14:00–17:00 두 현장이 표시됩니다.
- 혜화 미배정 현장에 10:00–11:00 배정을 시도하면 시간중복 경고가 나옵니다. 확인 체크 후 관리자가 강제 저장하면 기존 일일작업 목록에도 해당 기록이 저장됩니다.
- 월간/주간/작업진행자별 전환, 같은 날 여러 카드, `+N 더보기`의 전체 목록 확인.
- 현장명은 현장 상세, 작업진행자명은 해당 작업진행자 상세로 이동합니다.
- 모바일 390×844: 작업진행자별 카드 6개, 날짜/이름/현장/시간/상태 표시. 접이식 필터에서 작업진행자+현장을 동시에 선택하면 해당 카드만 남습니다.
- 모바일 표 보기: 문서 가로폭 390px로 화면 초과가 없고, 표 자체만 내부 스크롤됩니다(표 1420px / 컨테이너 264px).
- 모바일 주간 보기는 날짜 카드로 표시합니다. 브라우저 pageerror 0건.

메모리 샘플은 API 재시작 시 복원됩니다. 브라우저 검증 중 생성한 배정은 실제 PostgreSQL 저장이 아닙니다. 로그인 없는 현재 샘플 신원은 관리자이며, 작업진행자/직원 신원 및 다른 회사 접근 검증은 신뢰된 서버 문맥을 사용하는 API 테스트로 수행했습니다.
