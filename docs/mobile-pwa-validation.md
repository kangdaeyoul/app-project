# 모바일 PWA 검증 기록

2026-10-10, Chromium 반응형 브라우저로 검증. Android 크기 412px, iPhone 크기 390px(터치/iPhone UA), PC 1440px. 실제 Android/iOS 하드웨어의 카메라 권한과 홈 화면 설치는 외부 HTTPS 배포 후 추가 확인이 필요하다.

- 프로젝트 production build, TypeScript 타입 검사: 통과.
- API 테스트 71개: 통과. 기존 회사별 격리, 세션 인증, 견적/Excel/PDF/자재/스케줄/A/S/정산 회귀 검사 포함.
- 데모 관리자/사내직원/작업진행자 1·2 세션과 운영용 데모 비활성 설정: 통과.
- 관리자 모바일 홈 → 일정 → 현장 → 견적: 통과.
- 모바일 견적 즐겨찾기 감지기 3회 선택 → 수량 3 → 저장 → PDF/실제 Excel 양식 출력: 통과. 미등록 단가는 임의 생성하지 않음.
- 작업진행자 일정 → 작업 시작 → 전 사진 실제 multipart 업로드 → 작업내용 → 시험/정상작동 확인 → 완료요청: 통과. 저장된 작업완료 상태/사진 건수/확인 내용 검증.
- 긴급 A/S 배정 → 작업 시작 → 전·후 사진 2장 → 작업 종료 → 관리자 완료요청 → 처리결과 PDF: 통과. PDF 한글 텍스트와 이미지 2개 포함 확인.
- 작업지시 읽음과 알림센터, 본인 일정 및 사내직원 내부정보 비노출: 통과.
- 작업진행자 견적/타인 일정 접근 403, 회사 격리 및 사진 업로드·삭제 범위: 통과.
- manifest standalone/아이콘 192·512·180 크기, 서비스 워커 등록: 통과.
- 공용 오프라인 페이지와 아이콘만 캐시, 인증·업무 응답 비캐시, 오프라인 안내 표시: 통과.
- PC 화면 기존 대시보드 유지, 모바일 주요 화면 body 가로 넘침 없음, 브라우저 런타임 오류 없음.

브라우저 테스트는 서버의 샘플 메모리 데이터에만 기록을 추가했다. 기존 견적과 원본 사진은 변경하지 않았다. 검증용 생성 파일과 스크린샷은 저장소에 포함하지 않는다.
