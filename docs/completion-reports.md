# 완료보고서

현장 상세의 **완료보고서** 탭에서 공사 완료보고서 또는 보수 완료보고서를 작성합니다. 회사명과 확인란의 회사 표기는 현재 회사 설정을 사용합니다. 종로소방의 기본값은 주식회사 종로소방입니다.

- 자동 작업 요약·특이사항은 5,000자까지 불러오며 긴 내용은 말줄임 표시합니다. 날짜별 작업내용은 전체 기록을 유지합니다.
- 일일작업의 날짜별 내용, 대표 작업진행자와 참여자, 특이사항을 자동으로 불러옵니다. 날짜별 내용과 본문은 보고서에서만 수정되며 원본 기록에는 반영하지 않습니다.
- 사용자재는 현장 전체 기록에서 자재명·규격·단위가 같은 항목을 합산합니다. 구매가격, 내부 원가, 마진은 포함하지 않습니다.
- 작업기간은 출력 문구이며 데이터 조회 범위를 제한하지 않습니다. 날짜별 작업내역과 사용자재는 현장 전체 기록을 사용합니다.
- 사진은 전/후/모두, 전체/선택한 사진, 사진 목록/사진대지를 조합합니다. 연결 사진이 없는 현장도 본문 PDF를 생성할 수 있습니다. 선택한 사진만 출력하는 경우 최소 한 장을 선택해야 합니다. 최대 60장입니다.
- 기존 사진대지 렌더러의 날짜·위치별 전후 비교, 한글 폰트와 사진 설명을 재사용합니다. 사진 원본을 변경하지 않습니다.
- 실제 PDF 미리보기 이후 다운로드합니다. 내용을 바꾸면 미리보기가 초기화됩니다. 현장 기록을 새로 불러오면 작성 내용이 초기화되므로 확인 메시지를 표시합니다.

## API와 저장

- `GET /api/sites/:siteId/completion-reports/source`: 작성 기본값, 현장, 작업자 선택 목록, 자재 합계, 사진
- `POST /api/sites/:siteId/completion-reports/preview`: 임시 본문+사진 PDF 응답
- `POST /api/sites/:siteId/completion-reports/generate`: 회사별 저장소에 보관 후 다운로드 응답

관리자는 회사 내 현장에 접근하며 일반 사용자·조회자는 서버의 `accessibleSiteIds`에 포함된 현장만 조회·출력할 수 있습니다. 다운로드 파일 생성·응답은 기존 감사로그에 현장 범위로 기록됩니다.

`CompletionReportInput`, `CompletionReportSource` 공통 타입과 `CompletionReportStorage` 저장 포트를 분리했습니다. 현재 보고서 초안은 브라우저 상태에만 존재하며 생성 PDF는 회사별 임시 메모리 저장소(30분, 최근 20개)에 보관합니다. 서버 재시작 시 없어집니다. NAS 저장 키는 `companies/{companyId}/{siteId}/06 완료보고서/{uuid}/{filename}`이며 나중에 영구 저장 어댑터로 교체할 수 있습니다. 실제 NAS·PostgreSQL 연결은 하지 않습니다.

PDF는 NanumGothic 폰트를 내장하고, 본문과 기존 사진대지 PDF를 pdf-lib로 병합합니다. 파일명은 `현장명_공사완료보고서_작성일.pdf` 또는 `현장명_보수완료보고서_작성일.pdf`입니다.
