# 소방 보수공사 표준작업 구성품

견적 메뉴의 `표준작업 구성품 · 자재단가`에서 16개 작업 템플릿을 조회·수정합니다. 견적 작성/수정 중 계산한 구성품을 을지에 추가하며, 모든 수량과 단가는 기존 견적 편집기로 다시 수정할 수 있습니다.

초기 단가와 수량은 검증된 실거래 데이터가 아닌 샘플 기준값입니다. 감지기 5개는 전선 35m, 전선관 25m, 설치/결선 0.8인으로 설정했습니다. 길이 입력 0은 기본 작업수량×기준길이를 사용합니다. 재사용 옵션은 해당 구성품을 제외합니다. 작업수량 비례/고정/길이/1식/직접입력을 지원합니다. 직접입력 0 또는 수량 재정의 0은 해당 항목을 제외합니다.

관리자가 자재/노무의 내부 원가와 판매 단가를 별도 관리합니다. 고객 묶음 출력은 견적에 저장된 옵션이며 PDF/Excel/고객 미리보기에 공통 적용됩니다. 같은 공종·고객금액분류·묶음명에 속하는 항목의 판매금액을 합산해 1식으로 표시합니다. 내부 세부항목과 원가는 유지되고 고객 DTO는 원가·마진·템플릿 출처를 포함하지 않습니다. 서로 다른 고객금액분류는 금액분류를 보존하기 위해 별도로 묶습니다.

템플릿 수정은 이전 버전 덮어쓰기가 아닌 새 버전입니다. 버전 번호로 동시 변경을 감지하며 변경자·시각·사유·구성품·당시 단가 스냅샷을 보존합니다. 계산한 견적항목은 템플릿 ID/버전/구성품 ID와 당시 단가를 보관합니다. 이후 템플릿이나 단가를 변경해도 기존 견적은 바뀌지 않습니다. 관리자에게 버전별 전체 스냅샷 조회 API를 제공하므로 과거 견적 분석에 활용 가능합니다.

API: `GET /standard-work`, `POST /standard-work/prices`, `PUT /standard-work/prices/:id`, `PUT /standard-work/:id`, `GET /standard-work/:id/history`, `POST /standard-work/:id/calculate`. 모든 API는 현재 회사의 관리자 권한을 확인합니다. 외부 요청으로 회사나 사용자 ID를 선택할 수 없습니다.

현재 메모리 저장소 인터페이스를 유지합니다. PostgreSQL 이전 시 `work_prices`, `standard_work_templates`, `standard_work_versions`, `standard_work_components`에 company_id를 적용하고 복합 외래키, 버전 유일키, 템플릿 행 잠금으로 동시 변경을 막아야 합니다. 버전 스냅샷과 견적 구성품의 출처/단가 스냅샷을 독립 보존합니다. 재시작 시 샘플 상태로 돌아갑니다. 일반 변경이력 화면과 별도로 템플릿 전용 버전 이력을 관리합니다.
