# 견적 빠른입력과 회사 공통 즐겨찾기

견적 작성 화면 상단에서 자재DB 검색, 즐겨찾기 버튼, 직접 입력을 사용할 수 있습니다. 추가할 기계/전기 을지를 선택합니다. DB와 즐겨찾기는 클릭당 수량 1, 표준작업은 계산된 모든 구성품의 수량을 추가합니다.

견적 옵션은 `autoPrice`, `mergeDuplicates`, `mergeAcrossSources`로 저장합니다. 자동합산은 기본 ON입니다. 동일 항목은 자재코드 + 품명 + 규격 + 단위 + 고객금액분류로 판별하며 합산 시 기존 행의 모든 단가를 보존합니다. 규격/단위/코드가 다르면 별도 행입니다. 자동·수동 병합 OFF는 수동 입력이 포함된 행과 자동 입력 행을 분리합니다. DB·즐겨찾기·표준작업은 모두 자동 입력으로 판단합니다. 코드 없는 수동 항목은 코드 있는 DB 항목과 병합되지 않습니다. 수동 입력에서 DB 코드를 입력하면 같은 이름·규격·단위의 DB 항목과 병합 가능합니다.

단가 자동입력 OFF는 원가 및 판매단가 0원으로 추가합니다. 이미 들어간 행의 가격이나 수량은 옵션 전환과 DB 단가 변경으로 수정되지 않습니다. 회사 기본값 변경은 새 견적에만 적용됩니다. 품목마다 manual/catalog/favorite/standard 출처와 표준작업 ID·버전을 저장하며 고객 PDF/Excel DTO에는 내부 출처 및 원가가 포함되지 않습니다.

즐겨찾기는 회사별 메모리 저장소에서 순서 있는 자재코드 목록으로 관리합니다. 추가·해제 및 앞/뒤 이동을 지원합니다. `GET/PUT /standard-work/favorites`는 회사 관리자 권한을 요구하며 타 회사 품목 ID나 중복 ID를 거절합니다. 사용자별 확장을 위한 userId는 현재 null(회사 공통)입니다. PostgreSQL 이전 시 `quote_favorites(company_id,user_id,price_id,position)` 및 회사 복합 FK를 적용하고 회사 공통 scope의 유일성과 순서를 보장해야 합니다. 회사 기본값 API는 `PUT /company/quote-preferences`입니다.

단가·즐겨찾기·견적은 기존 메모리 방식으로 서버 재시작 시 초기화됩니다. 샘플 단가와 노무는 현장별 검토가 필요합니다.
