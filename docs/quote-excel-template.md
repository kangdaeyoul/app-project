# 종로소방 실제 Excel 견적서

견적 상세의 **종로소방 Excel 다운로드** 버튼은 저장된 견적과 선택한 고객 출력모드를 사용합니다. 수정 중이면 저장 후 출력합니다. 기존 PDF 출력과 견적 데이터 구조는 유지합니다.

첨부 `2026견적서.xlsx`의 견적서(갑지), 을지(기계), 을지(전기)를 기반으로 셀 너비·높이, 병합, 서식, 회사정보, 로고·인장, 인쇄영역, 머리글·바닥글과 프린터 설정을 보존합니다. 원본 파일을 수정하지 않습니다. 배포용 템플릿은 `apps/api/fixtures/quotes/jongno-2026.xlsx`이며, 기존 데이터·수식·계산 캐시·공유문자열·원본 경로 메타데이터를 제거했습니다. 승인된 회사정보 및 양식 표제만 남깁니다.

## 데이터 대응

- 갑지 E6 견적일, E7 현장, E8 주소, E9 거래처, E10 연락처. 기존 담당자 표제를 거래처로 바꾸고 담당자는 비고란에 표시합니다.
- C16:C19 기존 주자재/배관자재/전기자재/노무비 위치 유지. C20:C23 경비/일반관리비/착·준공지원비/반올림 조정 추가.
- E12 및 J30 기존 공급가액 합계 위치 유지. J24 공급가액, J25 VAT, J26 VAT 포함 총액을 추가하여 기존 고객가격 계산과 일치시킵니다. 금액은 실제 양식에 맞춰 원 단위로 출력합니다.
- B32:K39 기존 비고란에 공사내용, 유효기간, 담당자, 금액 기준 및 견적 비고를 표시합니다.
- 을지는 B 품명, C 규격, D 단위, E 수량, F 고객 판매단가, G 고객 금액, H 비고입니다. 원가 단가를 채우지 않습니다.
- 기존 고객금액 분류의 노무비와 경비는 을지 노무비·경비 영역에 표시합니다. 재료비는 품명으로 배관(강관/엘보/티 등), 전기 보조자재(전선/케이블 등), 나머지 주자재로 배치합니다. 전기 보조자재 판정을 먼저 적용합니다. 원본 견적항목이나 가격은 변경하지 않습니다.
- 입력 줄 초과 시 같은 양식의 계속 을지를 추가하고 각 을지 소계는 해당 시트의 판매금액 합계입니다. 갑지에는 전체 견적 합계가 표시됩니다.
- 출력모드: 전체 상세, 단가 숨김, 금액 숨김, 공종별 묶음, 총액 위주. 숨긴 가격은 셀 데이터에도 포함하지 않습니다.

`GET /api/quotes/:id/excel?mode=전체 상세`는 고객 공개 필드만 허용하는 별도 투영을 사용합니다. 내부 원가·마진·내부 관리비는 렌더러 입력에 포함하지 않습니다. 수식을 생성하지 않아 사용자 문자열이 Excel 수식으로 실행되지 않습니다. PostgreSQL 및 NAS 의존성은 없습니다.

템플릿 재준비: 저장소 루트에서 `node scripts/prepare-quote-template.cjs "원본.xlsx"`. 원본 파일은 유지하고 정제된 배포 템플릿만 갱신합니다. 변경 시 API 테스트 및 Excel 인쇄 검증을 다시 실행합니다. Windows Excel에서 원본의 돋움/맑은 고딕 등 폰트가 설치되어 있으면 원본 서식으로 표시됩니다. 다른 운영체제에서는 설치된 대체 폰트에 따라 글자폭이 달라질 수 있습니다.
