# 소방공사 통합 표준작업 자동견적

## 최초 기본 데이터

종로소방 회사에 전기 51종, 기계 52종, 총 103종의 기본 작업을 등록한다. 감지기·유도등·발신기·발신기세트·경종·표시등·시각경보기·비상조명등·스피커·중계기, 수신반·방송·회로보수·제연댐퍼, 스프링클러·밸브·배관·펌프·기계실·소화전·피난기구 작업을 포함한다.

모두 `검토필요`로 시작하며 최초 노무계수 등은 **예시 견적 기준**이다. 법정 표준 또는 확정 설계·시공물량으로 취급하지 않는다. 관리자는 구성품과 계수를 수정한 후 `사용승인` 상태로 새 버전을 저장할 수 있다. 승인 사용자·시각과 이전 버전의 구성품/연결 단가 스냅샷을 보존한다. 미입력 경로·회로·부속수량은 승인을 받더라도 자동 확정하지 않는다.

기본 자재는 기존 회사 DB의 이름·규격·단위에 맞춰 연결한다. 없는 품목만 생성하고 매입/원가/판매단가는 모두 0과 `priceRegistered=false`로 저장한다. 화면에서는 금액을 **미등록**으로 표시한다. 기존 실제 등록 단가를 덮어쓰지 않는다. `기본 표준작업 등록 (중복 방지)` 버튼 및 `POST /api/standard-work/initialize-defaults`는 회사/기본 작업 키를 사용한다. 재실행 시 관리자가 수정·승인·비활성화·삭제한 작업을 복원하거나 중복 생성하지 않는다. 메모리 재시작 시에는 샘플 초기값으로 돌아간다.

## 견적 입력

견적 작성 → 빠른입력의 **표준작업** 탭:

1. 작업을 검색해 하나 또는 여러 작업을 선택한다.
2. 각 작업수량과 공통 작업묶음을 입력한다.
3. 시공방법·재사용·제품 규격·실제 경로/개소/회로수를 선택한다.
4. 필요하면 공유 경로를 추가하고 각 작업에 동일 경로를 지정한다.
5. `구성품 자동계산 · 미리보기`에서 수량·단가·계산근거·자동/수동 표시를 확인한다. 행별 수정·삭제 가능하다.
6. `견적서에 반영` 후 기존 견적 항목과 합산하고 초안으로 저장한다.

수량 미확정 항목은 `quantity=0, quantityPending=true`로 보관한다. 미등록 단가는 `saleUnitPrice=0, pricePending=true`다. 의미 있는 실제 0과 미등록을 플래그로 구분한다. 수량·단가를 직접 수정하면 해당 미확정 표시를 해제한다. 미확정 수량 또는 미입력 단가가 있는 견적은 작성중/수정요청으로 보관할 수 있고 제출·승인 전에 확인해야 한다. 고객용 PDF/Excel에는 초안·예시수량 안내를 비고로 표시한다.

단일 자재·즐겨찾기·표준작업의 중복 합산 ON/OFF 및 수동/자동 출처 병합 설정은 유지한다. 품목 코드·명칭·규격·단위·금액분류가 같아도 서로 다른 명시적 시공조건은 분리한다. 자동 계산을 다시 반영해도 기존 판매 수정단가는 유지한다. 저장된 견적은 단가DB/템플릿 변경으로 재계산하지 않는다.

## 산출과 조건

- 감지기 연기식/차동식/정온식은 베이스 포함 품목이며 별도 베이스를 넣지 않는다.
- HFIX 1.5SQ/2.5SQ는 별도 품목. 실제 전선길이를 입력하거나 `경로길이 × 가닥 수 + 여유분`으로 계산한다. 수신반·중계기·방송·동력회로에는 별도의 선종 확인 품목을 사용하며 HFIX를 일괄 강제하지 않는다. 필요한 다른 전선은 자재DB에 등록한 후 구성품 규격 연결을 변경한다.
- 강재/SF/GW 16/22/28/36mm 전선관과 규격별 박스·커버·커넥터·커플링·새들을 연결한다. 박스는 설치 개소, 커넥터는 접속 개소, 커플링은 연결 개소, 새들은 길이/고정간격 올림 또는 직접 고정개소로 계산한다. 피스·앵커는 개소당 수량을 별도 입력한다.
- 노출/천장 은폐/벽체 매립과 배선·배관·기구 재사용은 조합 가능하다. 재사용하면 해당 신규 자재를 제외하고 필요한 접속단자·커넥터·노무를 남긴다. 은폐 시 노출 고정부속을 제외한다. 불필요한 항목은 미리보기에서 삭제하거나 구성품 조건으로 제외한다.
- 발신기세트 완제품을 선택하면 발신기·경종·표시등·함의 개별 자재비를 제외한다. 기존 함 재사용도 지원한다.
- P/R/복합 수신반, 회로수별 결선노무·단자·회로확인, 선택형 프로그램/중계기설정/통신/연동시험을 지원한다.
- 상향식 헤드에는 자바라를 제외한다. 하향식 자바라 선택 시 조인트·브래킷을 포함한다. 백관/CPVC/동관 25A~100A와 나사/그루빙/용접/CPVC 접합방식별 부속을 분리한다. 이음쇠는 직접 산출하고 배관길이/고정개소와 독립 관리한다. 다른 종류나 규격의 자재를 연결하면 호환 경고를 표시한다.
- 펌프 용량/접속규격·피난기구 설치높이 등을 확인하도록 안내한다. 미입력 상세제품을 자동 선정하지 않으며 관리자가 DB 품목을 연결한다.
- 노무는 작업수량, 기본+추가, 인원×일수, 작업묶음 고정수량으로 설정할 수 있다. 전기공/기계공의 회사별 노무단가는 회사 자재·노무DB에서 관리한다.

## 복합공사와 공통 수량

`POST /api/standard-work/composite`는 `batchId`, `tasks`, `routes`, `autoPrice`를 받는다. 각 작업의 `estimate.routeGroup`은 미리 등록된 실제 경로를 참조한다. 경로의 총길이·총개소를 기준으로 같은 경로/규격/조건의 배선·배관·고정부속은 최댓값을 한 번 반영한다. 여러 독립 경로는 합산한다. 작업수량만 보고 공유 경로를 추정하지 않는다. 예를 들어 감지기 5개 + 유도등 3개라도 공유 박스가 총 8개라면 경로에 8개를 입력해야 한다.

같은 작업묶음의 잡자재·시험비는 `commonKey`로 구분하고 한 번 반영한다. 별도 작업묶음은 별도로 계산한다. 상세 잡자재 모드에서는 세부 품목을 사용하고 묶음 잡자재는 제외한다. 같은 기본+추가 노무를 추가하면 작업수량 누적 이력을 이용해 기본노무를 중복 계산하지 않는다. 수동 변경한 노무는 재계산하지 않는다.

정보가 부족하면 0을 확정값으로 제시하지 않고 **현장산출 필요**로 남긴다. 서로 다른 경로나 규격의 공통 자재를 무조건 삭제하지 않는다. 향후 도면/AI 산출은 `WorkEstimateOptions`를 생성하는 별도 산출 어댑터로 확장할 수 있다.

## 관리자와 고객 출력

기존 `표준작업 구성품 · 자재단가` 관리화면에서 추가·복사·수정·삭제·활성/비활성·순서·조건·검토 상태를 관리한다. 구성품의 **산출·규격 연결 설정**에서 계수, 기본/추가 노무, 공통 키, 종류·규격별 실제 자재DB 연결을 수정한다. 새 품목은 자재관리에서 등록하거나 Excel로 반영한다.

고객 출력의 구성품 묶음 옵션은 부속류·배선 및 부속·배관 및 부속·설치 및 결선비를 묶는다. 내부 화면에는 실제 상세항목을 보존한다. 고객 DTO에 내부원가·마진·단가스냅샷·자동산출 메타데이터를 전달하지 않는다. 기존 종로소방 갑지/기계/전기 Excel 템플릿과 한글 PDF 출력 경로를 그대로 사용한다.

## 향후 PostgreSQL

회사 범위 저장소 인터페이스를 유지한다. `materials`의 단가 등록 상태/호환 속성, `standard_work_templates`의 회사·seed_key·검토/승인·버전, `standard_work_template_items`의 수량 규칙/규격 연결/공통 키, `standard_work_conditions`, `standard_work_versions`로 분리 가능하다. 견적 항목에는 당시의 수량·금액·입력출처·규칙 버전·산출 근거·미확정 상태를 스냅샷으로 보관한다. 모든 조회·관리 API는 회사 관리자 권한과 회사 데이터 경계를 확인한다.

## 검증

API 통합 테스트는 103개 작업군, 지정 시험견적 10종, 감지기 베이스 미분리, HFIX/전선관 규격, 경로 산출, 재사용, 완제품 중복 방지, 수신반 회로노무, 헤드/자바라 및 접합방식, 규격 경고, 공유경로·공통비, 등록 단가/자동단가 OFF, 저장·수정단가 보존, 승인·재등록·삭제 유지, 회사 격리, 고객 DTO·PDF·실제 Excel 출력과 기존 기능 회귀를 확인한다. 브라우저에서 복합작업 미리보기·수정·저장·재조회·한글 PDF 및 실제 Excel 다운로드를 검증한다.
